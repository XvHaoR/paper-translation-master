# Zotero で論文を対訳する「论文翻译大师」

[简体中文](../../README.md) · [English](en.md) · [日本語](ja.md) · [Español](es.md) · [Français](fr.md) · [Deutsch](de.md)

PDF の横に認識結果や訳文を表示します。図注の位置がずれたときは、ブロックを移動して直せます。題名を思い出せない論文も、覚えている内容から検索し、該当箇所を開けます。

## 0.8.2 のインストール

1. Zotero 7–10 に対応しています。Mac 版の対象は macOS 14 以降の Apple シリコン搭載機です。お使いの環境に合う ZIP をダウンロードしてください。[Windows x64](https://github.com/XvHaoR/paper-translation-master/releases/download/v0.8.2/paper-translation-master-windows-x64-0.8.2.zip) · [macOS arm64](https://github.com/XvHaoR/paper-translation-master/releases/download/v0.8.2/paper-translation-master-macos-arm64-0.8.2.zip)
2. Zotero を終了し、ZIP を今後も使用するフォルダーに展開します。Windows では `Install.cmd`、Mac では `Install.command` を実行します。
3. Zotero の「ツール → プラグイン」を開き、歯車メニューから同じフォルダーの XPI をインストールして再起動します。更新時も実行環境と XPI の両方を入れ替えてください。

## 最初の一篇を読む

文字を選択できる PDF には「直接解析 PDF」が使えます。スキャン文書には、ローカル OCR、飛桨や MinerU のクラウド、自分で運用する MinerU を選べます。クラウドを選ぶと、対象の PDF がそのサービスに送信されます。翻訳には設定画面でモデルと接続先を指定します。

「逐段双语」で原文と訳文を段落ごとに読めます。訳文につけたメモは訳文内に残り、原文で位置を特定できる箇所は Zotero の PDF にもハイライトできます。[画面を見ながら使い方を確認する（中国語）](../TUTORIAL.md)
