# 升级到 0.7.1 融合预览版

## 安装顺序

1. 关闭 Zotero。下载融合版 Windows 完整包，解压到准备长期保留的目录，运行 `Install.cmd`。
2. 从文件安装包内 XPI 并重启 Zotero。插件 ID 与旧版一致。
3. 在插件设置选择识别方案，并核对翻译设置。预览版采用手动更新，运行环境跟随完整包升级。

## 沿用本地或云端 OCR

- **0.5.0 GPU／CPU** 用户可保留原引擎。在融合版设置中检测引擎，选择本地 OCR 并保存。
- **WSL FastDeploy** 用户可以沿用已注册的 Python 和模型。模型服务须能启动，融合版使用兼容的运行目录。手动指定环境时，项目目录应使用融合版源码，Python 路径指向原 OCR 环境，运行方式选择 WSL FastDeploy。
- **0.6.0 云端版** 用户选择云端 OCR，核对飞桨 Access Token。若翻译设置保存在旧引擎工作区，在融合版设置中重新填写。

## 已保存的文献附件

来自旧版的识别结果和译文可以直接打开。插件启动时将同一可写文献库中、来源明确的独立结果归到原 PDF 所属的文献条目。独立 PDF 会建立通用文档父条目。原文件、批注和收藏分类保留，变更前的层级记录保存在 Zotero 配置目录的 `paperloom` 文件夹。

要重新翻译缺少可验证原文快照的历史结果，请先用融合版生成新的识别结果。
