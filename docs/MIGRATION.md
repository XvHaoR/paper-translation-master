# 升级到 0.7.0

0.7.0 将此前 `editions/native` 中的本地解析版 0.4.2 作为仓库主版本。今后安装、开发和构建均从仓库根目录开始。版本号高于原云端版 0.6.0，避免安装时混淆新旧版本。

## 从本地解析版 0.4.x 升级

1. 关闭 Zotero，将新源码或安装包放到准备长期保留的目录。
2. 在新目录运行 `Install.cmd` 或 `python install.py`，注册新的解析环境并生成 XPI。
3. 在 Zotero 中从文件安装 `dist/paper-translation-master-0.7.0.xpi`，重启后在设置中检测已安装引擎。

插件 ID、解析结果格式及本地解析数据目录保持不变。使用标准安装器注册的工作区和翻译设置继续沿用；若曾手动指定工作区，请保留原配置并在升级后核对设置。已有 PDF、解析与译文附件继续保存在 Zotero 文献库中，本次目录调整无需重新解析或翻译。

## 从云端 OCR / GPU / RapidOCR 版升级

请使用新目录及本版创建的 Python 环境，避免覆盖旧目录中的本机配置或混用旧依赖。新版安装后替换同一插件 ID 的旧插件；重新检测解析环境，并填写翻译服务配置。旧环境中的工作区和密钥不会被源码安装器自动导入。

新版本从 PDF 文字层提取内容并分析版面，不安装或调用 OCR，也无需飞桨 Token、GPU 或 WSL。扫描件及无法提取文字的区域保留图像供核对，不能直接得到其中的可翻译文字。阅读已有保存结果与重新解析是不同操作；升级不会自动重写已有译文。

仓库根目录不再包含旧 OCR 服务、旧安装器或浏览器扩展。需要这些功能时，可通过仓库的 `v0.6.0`、`v0.5.0` 等原有标签和 [历史 Releases](https://github.com/XvHaoR/paper-translation-master/releases) 获取对应版本。历史版本不与 0.7.0 的运行环境混装。

## 附件层级

原 PDF、解析、译文和 Markdown 归到同一文献父条目下。独立 PDF 自动创建仅含标题的通用文档父条目；旧结果只在来源明确且有写入权限时整理。关系变更前保存本机备份，附件文件、批注和标签保留。
