# 0.6.0 云端版发布核查

- 单元／集成／DOM：385 项测试通过。新增云端任务、图片下载不转发密钥、上传来源限制等检查。
- Windows Zotero 10.0.8 隔离文献库：145 项原生检查通过，覆盖启动、字体、PDF 对照、公式复制、表格导出、编辑同步、批量与独立队列及退出清理。
- 使用最终云端 XPI 与轻量运行环境：7 项检查通过，真实飞桨接口解析合成 PDF 并保存为可编辑 Zotero 附件；保留版面坐标，退出后服务停止。
- 轻量环境验证未安装 Paddle、PaddleOCR、PaddleX、RapidOCR 或 ONNX Runtime，不包含本机 OCR 模型。
- GPU 与 CPU 原有安装包和本地完整部署文档均保留。云端与本地更新通道独立，旧本地用户不自动切换运行方式。
- 发布包与源码经过白名单打包、版本一致性和密钥排除检查；不包含用户论文、配置、密钥、测试工作区或私有仓库历史。

测试只覆盖列明的环境和样本，不能代表所有设备、论文及云端队列状态。
