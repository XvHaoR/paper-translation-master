# 0.5.0 发布验证

本次将 HTML 阅读探索版整理为正式发布，保留公开仓库的 RapidOCR CPU 适配与独立 OCR／翻译队列。

- 本地 Python／JavaScript／DOM 单元与集成测试：369 项通过。
- Windows Zotero 10.0.7 独立配置、独立文献库回归：141 项检查通过，包括启动进度、阅读模式、字号颜色、PDF 定位、语义图表组合、大图、HTML 导出与重开、公式复制、Excel 导出、编辑保存、并行队列和真实退出清理。
- 此次原生回归使用固定 PDF 与测试翻译接口，不将测试调用数或模拟接口描述为生产模型的准确率、速度或质量验收。此前的实际论文 OCR 结果用于 HTML 校正验证。
- 通用 XPI 检查：无开发机路径或固定本地测试目录，保留插件 ID，导出协议版本 12，使用正式 GitHub 更新通道。
- GPU／CPU 两个安装器完成 PyInstaller 构建与内嵌资源自检；没有在本次发布中重新部署用户的 OCR 环境。
- 源码与引擎包经白名单和隐私规则检查，不包含用户论文、工作区、模型、API 配置或私有仓库历史；发布文件提供 SHA-256 校验。

安装器全新 Windows 环境的完整覆盖仍在补充，安装器没有 Windows 代码签名。原生回归不等同于所有平台、模型和论文的保证。
