# 本地解析版更新记录

此版本线独立于仓库根目录的云端/OCR 版。

## 0.4.1

- 在版面分析和遗漏文字补回之前，过滤符合版式、连续序列及字体特征的审稿行号。
- 同时支持左右页边、栏间、部分短页、每 5/10 行编号及旋转页面；存疑数字予以保留。
- 保留正文年份、统计数据和引用编号；仅处理内存中的解析副本，不修改原 PDF 或剩余文字的坐标。
- 升级自动解析缓存；再次主动翻译时避免返回基于旧版解析的译文。人工编辑的解析结果不被自动替换。
- 补充生成式 PDF 和译文缓存回归测试。

### 同仓库引入

- 将完整源码放入 `editions/native`，保留现有云端、GPU 和 CPU OCR 方案。
- 补充方案选择文档、独立 CI、源码包构建和第三方声明。
- 源码安装自动构建 XPI；按固定 NumPy 依赖将最低 Python 版本明确为 3.12。

## 0.4.0

- 使用本地 PDF 文字层和版面分析，移除本版必需的 PaddleOCR/云端识别配置。
- 支持单栏、多栏和混合版面，接回跨栏、跨页及图表之间的正文续段。
- 脚注独立显示，图表与注释分组；保留翻译、双向滚动和选句高亮。
- 扫描页或异常文字区域保留原图并提示核对。

## 已知限制

- 部分 Zotero 场景下顶部视图按钮首次点击可能不切换，实机排查暂缓。
- 本版不对扫描图像执行 OCR，不从公式图像生成 LaTeX。
- 复杂版式和非标准行号可能仍需人工核对。
